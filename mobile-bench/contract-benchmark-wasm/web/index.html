Midnight contract-benchmark · web

Runs contract_benchmark::run_proof(k) compiled to wasm32-unknown-unknown with wasm-bindgen-rayon threads. The wasm itself lives in a dedicated Worker — `SharedArrayBuffer`-backed thread pools require the wasm to be hosted off the main thread. SRS params are fetched on demand from /srs/<file> (the local server proxies to srs.midnight.network) and cached in IndexedDB.
